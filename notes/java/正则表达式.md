# 正则表达式

> 本笔记基于韩顺平老师的Java正则表达式教程整理，涵盖从快速入门到底层原理、语法详解、常用类到实战案例的完整知识体系。（全文由AI生成。）

## 为什么学习正则表达式

### 体验正则表达式的威力

假设我们需要从一篇长文章中**提取所有英文单词**、**提取所有数字**，或者**提取百度热榜的标题**——传统方式需要编写大量循环和判断代码，而正则表达式只需一行匹配规则即可完成。

```java
// 提取所有英文单词
Pattern pattern = Pattern.compile("[a-zA-Z]+");
// 提取所有数字
Pattern pattern = Pattern.compile("[0-9]+");
// 提取所有英文单词和数字
Pattern pattern = Pattern.compile("([0-9]+)|([a-zA-Z]+)");
```

**结论：正则表达式是处理文本的利器**，能把数小时的手工文本处理工作缩短到几分钟甚至几秒钟。

### 典型需求场景

- 找出字符串中所有四个数字连在一起的子串（如 1998、3443、9889）
- 验证电子邮箱格式是否合法
- 验证手机号格式是否正确
- 提取特定格式的URL信息


## 正则表达式底层实现原理

理解底层原理是精通正则表达式的关键。以匹配 `"1998"` 和 `"3443"` 为例，正则表达式为 `(\\d\\d)(\\d\\d)`。

```java
String content = "1998年...3443...9889";
String regStr = "(\\d\\d)(\\d\\d)";
Pattern pattern = Pattern.compile(regStr);
Matcher matcher = pattern.matcher(content);
```

### matcher.find() 的执行过程

1. 根据指定规则定位满足条件的子字符串（如 `1998`）
2. 将子字符串的**开始索引**记录到 `matcher` 对象的 `int[] groups` 数组：
   - `groups[0] = 0`（子串起始索引），`groups[1] = 4`（结束索引 +1）
3. 如果有分组 `()`，记录每个分组的匹配位置：
   - 第1组 `(\\d\\d)`：`groups[2] = 0`，`groups[3] = 2`（匹配 `"19"`）
   - 第2组 `(\\d\\d)`：`groups[4] = 2`，`groups[5] = 4`（匹配 `"98"`）
4. 记录 `oldLast` 为子串结束索引+1，下次 `find()` 从此位置继续匹配

### matcher.group() 的取值规则

```java
while (matcher.find()) {
    System.out.println("完整匹配: " + matcher.group(0));  // 1998
    System.out.println("第1组: " + matcher.group(1));     // 19
    System.out.println("第2组: " + matcher.group(2));     // 98
}
```

- `group(0)`：匹配到的完整子字符串
- `group(1)`、`group(2)`...：按左括号顺序编号的捕获组内容
- 分组编号不能越界


## 正则表达式语法

元字符（Metacharacter）从功能上分为六大类：

| 分类               | 说明                 |
| ------------------ | -------------------- |
| 字符匹配符         | 匹配单个字符         |
| 选择匹配符         | 在多个模式中选择匹配 |
| 限定符             | 指定字符重复次数     |
| 定位符             | 指定匹配的位置       |
| 分组组合符         | 对模式进行分组       |
| 特殊字符（转义符） | 转义特殊字符         |

### 转义符 `\\`

在Java正则表达式中，**两个反斜杠 `\\\\` 代表其他语言中的一个 `\\`**。

**需要转义的特殊字符：** `. * + ( ) $ / \\ ? [ ] ^ { }`

```java
String content = "abc$(a.bc(123(";
// 匹配 $ 符号
String regStr = "\\$";   // 正确
// 匹配 ( 符号
String regStr = "\\(";   // 正确
// 匹配 . 符号
String regStr = "\\.";   // 正确，不加转义则代表匹配任意字符
```

### 字符匹配符

| 符号  | 含义                                          | 示例           | 说明                             |
| ----- | --------------------------------------------- | -------------- | -------------------------------- |
| `[ ]` | 可接受的字符列表                              | `[efgh]`       | e、f、g、h中的任意1个字符        |
| `[^]` | 不接受的字符列表                              | `[^abc]`       | 除a、b、c之外的任意字符          |
| `-`   | 连字符（范围）                                | `A-Z`          | 任意单个大写字母                 |
| `.`   | 匹配除`\n`外的任意字符                        | `a..b`         | 以a开头b结尾，中间2个任意字符    |
| `\\d` | 匹配单个数字，等价于`[0-9]`                   | `\\d{3}(\\d)?` | 3个或4个数字                     |
| `\\D` | 匹配单个非数字，等价于`[^0-9]`                | `\\D(\\d)*`    | 非数字开头，后接任意数字         |
| `\\w` | 匹配数字/字母/下划线，等价于`[0-9a-zA-Z_]`    | `\\d{3}\\w{4}` | 3个数字+4个字母数字              |
| `\\W` | 匹配非数字/字母/下划线，等价于`[^0-9a-zA-Z_]` | `\\W+\\d{2}`   | 至少1个非数字字母，以2个数字结尾 |

```java
String content = "a11c8abc _ABCy @";
// 匹配 a-z 之间的任意一个字符
String regStr = "[a-z]";
// 匹配 0-9 之间的任意一个字符（不区分大小写匹配abc）
String regStr = "(?i)abc";
```

**注意：** `\\w` 还包含下划线 `_`，`\\W` 排除的范围相应扩大。

### 选择匹配符 `|`

用于在多个匹配规则中选择：

```java
String content = "hanshunping|韩|寒冷";
String regStr = "hanshunping|韩";  // 匹配 hanshunping 或 韩
```

### 限定符

指定前面的字符或组合项连续出现的次数。

| 符号    | 含义      | 示例     | 匹配                      |
| ------- | --------- | -------- | ------------------------- |
| `*`     | 0次或多次 | `a*`     | 空或任意个a               |
| `+`     | 1次或多次 | `a+`     | 至少1个a                  |
| `?`     | 0次或1次  | `a?`     | 空或1个a                  |
| `{n}`   | 恰好n次   | `a{3}`   | `aaa`                     |
| `{n,}`  | 至少n次   | `a{3,}`  | 3个及以上a                |
| `{n,m}` | n到m次    | `a{3,4}` | 3个或4个a（**贪婪匹配**） |

#### 贪婪匹配与非贪婪匹配

**Java默认使用贪婪匹配**：当有多种匹配长度可选时，优先匹配最长的。

```java
String regStr = "\\d{2,5}";
// 对于 "11111"，会匹配整个 "11111"，而不是 "11" 或 "111"
```

**非贪婪匹配**：在限定符后加 `?`，优先匹配最短的。

```java
String regStr = "\\d{2,5}?";  // 非贪婪，优先匹配2个
```

### 定位符

定位符指定匹配的**位置**（行首、行尾、单词边界等）。

| 符号  | 含义       | 示例               | 说明                    |
| ----- | ---------- | ------------------ | ----------------------- |
| `^`   | 起始字符   | `^[0-9]+[a-z]*`    | 以至少1个数字开头       |
| `$`   | 结束字符   | `^[0-9]\\-[a-z]+$` | 以数字开头，以字母结尾  |
| `\\b` | 单词边界   | `abc\\b`           | 匹配作为单词边界的abc   |
| `\\B` | 非单词边界 | `abc\\B`           | 匹配不作为单词边界的abc |

**整体匹配**：若要要求字符串**完全匹配**正则表达式，需同时使用 `^` 和 `$`：

```java
String regStr = "^[0-9]+$";  // 整串必须全是数字
```

### 分组

#### 捕获分组

用 `()` 将模式分组，匹配后可以通过编号或名称访问分组内容。

```java
// 非命名捕获（按编号访问）
String regStr = "(\\d\\d)(\\d\\d)";
// 分组1：前两位数字，分组2：后两位数字

// 命名捕获（按名称访问）
String regStr = "(?<g1>\\d\\d)(?<g2>\\d\\d)";
// 可通过 matcher.group("g1") 访问
```

#### 非捕获分组

使用 `(?:pattern)` 形式，匹配但不捕获，不存储供后续使用。

```java
// 非捕获分组
String regStr = "(?:\\d\\d)(\\d\\d)";  // 第一个分组不捕获，第二个正常捕获
```

非捕获分组是对选择匹配符 `|` 的补充和完善，常用于组合多个模式但不产生额外分组编号。


## 三个常用类

### Pattern 类

`Pattern` 对象是正则表达式对象，**没有公共构造方法**，通过静态方法 `compile()` 创建。

```java
Pattern pattern = Pattern.compile(regStr);
```

- **`matcher()`**：部分匹配，只要有子串满足正则表达式即可。若需整体匹配，要加定位符 `^...$`
- **`matches()`**：整体匹配，要求整个字符串符合正则表达式

### Matcher 类

`Matcher` 是匹配引擎，**也没有公共构造方法**，通过 `Pattern.matcher()` 获得。

| 方法               | 说明                                       |
| ------------------ | ------------------------------------------ |
| `find()`           | 尝试查找匹配该模式的输入序列的下一个子序列 |
| `find(int start)`  | 从指定索引开始查找                         |
| `matches()`        | 尝试将**整个区域**与模式匹配               |
| `lookingAt()`      | 尝试从区域开头开始匹配                     |
| `start()`          | 返回匹配的初始索引                         |
| `end()`            | 返回最后匹配字符之后的偏移量               |
| `group(int group)` | 返回指定分组捕获的内容                     |

### PatternSyntaxException

非强制异常类，表示正则表达式模式中的**语法错误**。


## 反向引用

**捕获**是指将分组匹配的内容保存下来，通过编号或名称访问。

**反向引用**是指利用捕获的**编号**去**使用**分组中的内容——在正则表达式内部使用 `\组号`，在外部使用 `$组号`。

### 经典案例：结巴去重

将 "我我我....我要....学学学学....编程" 处理为 "我要学编程"。

```java
String content = "我我我....我要....学学学学....编程";
// 匹配重复的汉字
String regStr = "(.)\\1+";  // \1 反向引用第1组
// 替换为单个字符
String result = content.replaceAll(regStr, "$1");
```

### 匹配连续相同数字

```java
// 匹配 1221、5775 这种形式（第1位=第4位，第2位=第3位）
String regStr = "(\\d)(\\d)\\2\\1";
```

## 实战案例

### 验证邮箱格式

```java
// 简单验证：包含 @ 和域名
String regStr = "^[\\w-]+(\\.[\\w-]+)*@[\\w-]+(\\.[\\w-]+)+$";
```

### 验证手机号

```java
// 中国大陆手机号：1开头的11位数字
String regStr = "^1[3-9]\\d{9}$";
```

### 解析 URL

```java
// 提取协议、域名、端口、路径等
String regStr = "^(https?://)?([\\w-]+\\.)+[\\w-]+(/([\\w-./?%&=]*)?)?$";
```

### 提取百度热榜标题

```java
// 提取 <a target="_blank" title="标题内容">
String regStr = "<a target=\"_blank\" title=\"(\\S*)\"";
```


## 常见正则表达式速查

| 需求                   | 正则表达式                                    |
| ---------------------- | --------------------------------------------- |
| 数字                   | `^[0-9]*$`                                    |
| n位数字                | `^\\d{n}$`                                    |
| 至少n位数字            | `^\\d{n,}$`                                   |
| 非零开头的最多两位小数 | `^([1-9][0-9]*)+(\\.[0-9]{1,2})?$`            |
| 手机号                 | `^1[3-9]\\d{9}$`                              |
| 邮箱                   | `^[\\w-]+(\\.[\\w-]+)*@[\\w-]+(\\.[\\w-]+)+$` |
