# UU加速器 — 下载 & 安装 & 使用

解决游戏高延迟、无法连接、卡顿等问题。

---

## 1. 下载

打开官网 [https://uu.163.com](https://uu.163.com)，点击「下载」按钮。

支持：Windows / macOS / 手机端（iOS + Android）

## 2. 安装

- **Windows**：双击安装包 → 默认路径 → 下一步完成
- **macOS**：拖到 Applications 文件夹
- **手机**：应用商店搜索「UU加速器」

安装完成后打开，微信/手机号登录即可。

## 3. 添加加速

1. 搜索你要玩的游戏（Steam / 原神 / LOL / 吃鸡等）
2. 选择区服（亚服、美服、欧服）
3. 点击「立即加速」

等待 2–5 秒，连接成功后游戏图标上会显示延迟数值。

## 4. 常见问题

| 问题 | 解决 |
|------|------|
| 登录失败 | 微信扫码登录，不需要注册 |
| 加速后还是卡 | 切换节点，选延迟最低的 |
| 手机版怎么用 | 安装后开热点给游戏机/PC 用 |
| 免费吗 | 新用户有免费试用时长，后续付费 |

## 5. 小技巧

- 加速前先关掉其他 VPN/代理，冲突会导致加速无效
- 加速后如果游戏崩了，试试修改加速区域
- 手机加速 PC 时会创建虚拟局域网（类似局域网联机）
