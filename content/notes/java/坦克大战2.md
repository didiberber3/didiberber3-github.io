# 坦克大战2



如何实现当用户按下J键，坦克就发射一颗子弹



1. 发射一颗子弹后，就相当于启动了一个线程
2. Hero有子弹的对象，当按下J时，启动一个发射的行为（线程），让子弹不停的移动，形成一个射击的效果
3. 我们My Panel需要不停重绘，才能出现该效果
4. 当子弹移动到面板的边界时（或击中时），就应该销毁（启动的子弹的进程销毁）



考虑代码冗余不做粘贴，只做设计思路

1. 子弹被设计为一个类，实现了Runnable接口，设置子弹的属性（X Y Direction speed isLive默认为true）其XYD都可以用调用发射子弹方法的类中属性，稍作调整即可，在run方法中循环输出子弹位移，根据方向，设置在朝向某方向的位移距离，使用while true无限循环
2. 在while循环外加if判断子弹应该销毁的条件，在hero坦克类中创建shotBullet方法，
3. 根据Hero方向，调整子弹生成位置，新建Shot对象并启动线程
4. 在MyPanel中监听 当press J键时，调用hero对象的shotBullet方法，在paint方法中使用if判断语句，判断shot线程是否存在，子弹是否存活，如果为真，绘制子弹



# 让敌人的坦克也能发射子弹（可以有多个子弹）



1. 在敌人坦克类，使用Vector 保存多个Shot对象
2. 当每创建敌人坦克对象时，给该对象初始化一个Shot对象
3. 当绘制敌人坦克时，需要遍历敌人坦克对象Vector，绘制所有的子弹。当子弹`isLive ==false` 时，从Vector中移除



设计思路：

1. 给敌人坦克新建一个Vector集合，类型为Shot
2. 当敌人坦克射击时，创建新线程，取出shot
3. 在绘制敌人坦克时，需要遍历敌人坦克集合，绘制所有的子弹，当子弹isLive==false ，就从Vector中移除
4. 并且也要在敌方坦克集合enemyTanks中移除地方坦克，分别消除坦克的实体





# 让敌人的坦克随机的移动



设计思路：

1. 因为要求敌人的坦克，可以自由移动，因此需要将敌人的坦克作为线程使用

2. 需要将enemyTank实现Runnable接口作为线程，重写run方法，在实现run方法时，写上随机移动的业务代码

   ```java
       public void run() {
   //        写上相应的业务代码
   //        如自由移动
   
           while (isLive) {
   //            根据坦克移动方向来继续移动,
               switch (getDirection()) {
                   case 0:
                       movingUp();
   
                   case 1:
                       movingRight();
   
                   case 2:
                       movingDown();
   
                   case 3:
                       movingLeft();
   
   
               }
   
               try {
                   Thread.sleep(10);
               } catch (InterruptedException e) {
                   throw new RuntimeException(e);
               }
   
               setDirection((int) (Math.random() * 4));
   
               if (!isLive) {
                   break;
               }
   ```

3. 在创建敌人坦克对象时，启动线程

4. 限制坦克只能在画布内进行移动，不能超出画布外
