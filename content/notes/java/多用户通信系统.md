### 为Server创建service

```java
package com.jl.qqserver.service;

import com.jl.qqcommon.Message;
import com.jl.qqcommon.MessageType;
import com.jl.qqcommon.User;
import com.sun.security.ntlm.Server;

import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.net.ServerSocket;
import java.net.Socket;

//这是服务器,在监听9999,等待客户端的连接,并保持通信
public class QQServer {

	private ServerSocket serverSocket = null;

	public QQServer() {
//		端口可以写在配置文件中.
		System.out.println("服务端在9999端口监听....");
		try {
			serverSocket = new ServerSocket(9999);
			while (true) {
				Socket socket = serverSocket.accept(); // 如果没有客户端连接,那么就会阻塞在这里.
//				得到Socket关联的对象的输入流 用于接收消息
				ObjectInputStream ois = new ObjectInputStream(socket.getInputStream());
//				得到Socket关联的对象的输出流 用于回复消息
				ObjectOutputStream oos = new ObjectOutputStream(socket.getOutputStream());
				User u = (User) ois.readObject(); //读取客户端发送的User对象。
//				验证用户
				Message message = new Message();
				if (u.getUserId().equals(100) && u.getUserPsw().equals(123456)) { //登录通过
//					创建Message对象，准备回复客户端
//					验证
					message.setMessageType(MessageType.MESSAGE_LOGIN_SUCCEED);
//					将Message对象回复
					oos.writeObject(message);
//					创建一条线程，和客户端保持通讯,该线程需要持有Socket对象。
					ServerConnectClientThread sccThread = new ServerConnectClientThread(socket, u.getUserId());
					sccThread.start();
//					把该线程放入一个集合中,便于管理
					ManageServerConnectClientThread.addServerConnectClientThread(u.getUserId(), sccThread);
					//登录失败
				} else {
					message.setMessageType(MessageType.MESSAGE_LOGIN_FAILED);
					oos.writeObject(message);
					socket.close();
				}


			}


		} catch (Exception e) {
			throw new RuntimeException(e);
		} finally {
//			如果服务端退出了while循环,说明服务器端不再监听,整个后台都要退出,因此需要关闭资源
			try {
				serverSocket.close();
			} catch (IOException e) {
				throw new RuntimeException(e);
			}
		}


	}
}

```

## 第三部分：无异常退出

如果Server在持续监听Client，Client输入9退出系统，Client的控制台就没有退出，程序本身并没有退出，实际上是因为线程还没有关闭（Socket）如果强制退出（关闭控制台），Server端会直接报错



于是，对两端分别提出解决办法

**客户端解决办法**

1. 在main线程中，调用方法，给服务器端发送一个退出系统的Message对象
2. 调用`System.exit(0)`  //正常退出

**服务器端解决办法**

1. 服务器端和某个客户端通信的线程如果接收到了一个退出系统的Message后
2. 把这个线程持有的Socket关闭
3. 退出该线程的run方法（退出while循环）



不复制粘贴了，就是一些写几个方法，调用几个方法，

把这个线程持有的Socket关闭，需要写一个remove方法，将线程池中的这个线程从集合中移除，然后`socket.close()`

					ObjectOutputStream oos = null;
