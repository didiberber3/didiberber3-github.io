## 2. 工作原理

### 2.1 内容从哪里来？

所有内容都是 **Markdown 文件**，放在 `content/notes/` 和 `content/shares/` 文件夹里。

- 笔记按分类放子文件夹：`content/notes/java/`、`content/notes/排版/` 等
- 分享直接放 `content/shares/`，每个 `.md` 文件顶部有一段 "frontmatter"：

```markdown
---
title: 标题
date: 2026-01-15
tag: 工具
url: https://example.com
---
正文内容...
```

### 2.2 怎么加载到页面的？

分为两步：

**第一步：构建时索引**（Vite 插件 `contentIndexPlugin`）
- 打包时扫描 `content/` 下的所有 `.md` 文件
- 读取每个文件的 frontmatter（标题、日期等）
- 生成一个虚拟模块 `virtual:content-index`，包含所有文件的元数据
- 这样页面加载时不需要去读文件系统，直接 import 即可

**第二步：运行时懒加载**
- 笔记/分享的具体内容使用 `import.meta.glob` 做动态导入
- 只有用户点进某篇文章时，才会加载对应 `.md` 文件的内容
- 加载后用 `marked` 库把 Markdown 转为 HTML
- 然后用 highlight.js 给代码块着色

### 2.3 页面怎么切换？

- 使用 Vue Router 的 **hash 模式**（URL 里有 `#/`）
- 好处：不需要服务器配置，GitHub Pages 能直接支持
- 缺点：URL 比正常路径多一个 `#`，不够干净

### 2.4 主题切换怎么实现？

- CSS 自定义属性（变量）定义所有颜色
- 亮色模式在 `:root` 里定义，暗色模式在 `.dark` class 里覆盖
- 用户点击主题按钮时：
  1. 切换 `<html>` 的 `class="dark"`
  2. 保存偏好到 `localStorage`
  3. 下次打开页面时，在 Vue 挂载**之前**读取 localStorage，直接加 class
  4. 这样就**不会有闪白的问题**

### 3.3 设计语言

- **直角风格**：全站 `border-radius: 0`，无圆角
- **绿色强调色**：所有交互元素（链接、按钮、高亮）使用绿色系
- **简洁排版**：正文行高 1.8，字间距 0.01em，阅读体验宽松
- **响应式**：桌面端三栏，平板两栏，手机单栏

### 3.4 Tailwind 定制

`tailwind.config.js` 定制了两项：

1. **绿色色板** — 覆盖默认 gray 为 green 主题
2. **Typography 插件** — 限制 `.prose` 最大宽度 780px，行高 1.8

在实际组件中，Tailwind 主要用于布局（flex、grid、padding、margin），颜色和交互样式用 CSS 变量。

## 4. JavaScript / TypeScript 体系

### 4.1 代码组织原则

- **Composition API + `<script setup>`**：所有 Vue 组件使用 setup 语法
- **类型驱动**：关键数据结构用 TypeScript interface 定义
- **工具函数**：`utils/` 下放纯逻辑，与 Vue 解耦
- **懒加载**：路由组件和 Markdown 内容都使用动态导入

### 4.2 核心数据流

```
Markdown 文件
    │
    ▼
Vite 插件（构建时）
    │  读取 frontmatter → 生成 virtual:content-index
    │  import.meta.glob → 生成懒加载映射
    ▼
content.ts（运行时）
    │  getNoteList() → 只返回元数据（标题、日期、分类）
    │  loadNote(slug) → 加载并渲染 Markdown → 返回完整 Note 对象
    ▼
Vue 页面组件
    │  渲染 HTML + 代码高亮 + 目录导航
    ▼
用户看到最终页面
```

### 4.3 关键类型定义

```typescript
// 笔记元数据（列表用）
interface NoteMeta {
  slug: string
  title: string
  date: string
  category: string
}

// 完整笔记（详情用）
interface Note extends NoteMeta {
  content: string       // 原始 Markdown
  html: string          // 渲染后的 HTML
  toc: TocItem[]        // 目录结构
}

// 目录项
interface TocItem {
  level: number         // 2 或 3
  id: string
  text: string
}
```

### 4.4 代码高亮优化

原来三个页面（ArticleView、ShareView、DocsPage）各自独立 import 和 register highlight.js，代码重复。已经抽取到 `src/utils/highlight.ts`：

```typescript
// 统一注册所有用到的语言，三处页面只需调用 highlightBlocks()
import { highlightBlocks } from '../utils/highlight'
nextTick(() => highlightBlocks())
```

通过 tree-shaking 只加载 Java、Bash、Markdown、PowerShell 四种语言，避免加载 highlight.js 全部语言（几十个）。

## 5. 动画规范

> ⚠️ **原则：所有动画必须统一口径**，防止出现"改了 A 按钮的动画，B 按钮忘了改"的问题。

### 5.1 动画总览

> ⚠️ **2026-05-28 一致性修复**: 全站所有交互悬浮/选中过渡统一为 **0.2s ease**。  
> 过去存在 0.15s / 0.2s / 0.25s / 0.35s 四种速度混用的情况，现已全部归并。

| 动画 | 触发方式 | 实现手段 | 时长 | 缓动函数 | 所属 |
|------|----------|----------|------|----------|------|
| 页面切入 | 路由切换 → 自动 | CSS animation | 0.35s | ease-out | 全局 |
| 文章卡片悬浮 | 鼠标 hover | CSS transition | 0.2s | ease | 组件层 |
| 导航 Tab 选中 | 路由匹配 | CSS transition | 0.2s | ease | 组件层 |
| 导航 Tab 底部绿条 | hover/active | CSS transition（::after） | 0.2s | ease | 组件层 |
| 文章列表导航悬浮 | 鼠标 hover | CSS transition | 0.2s | ease | 组件层 |
| TOC 悬浮 | 鼠标 hover | CSS transition | 0.2s | ease | 组件层 |
| TOC h3 子项悬浮 | 鼠标 hover | CSS transition | 0.2s | ease | 组件层 |
| "全部 N 篇" 按钮填充 | 鼠标 hover | CSS transition（::before） | 0.2s | ease | 组件层 |
| "访问" 按钮填充 | 鼠标 hover | CSS transition（::before） | 0.2s | ease | 组件层 |
| 分类卡片顶部绿线 | 鼠标 hover | CSS transition（::before） | 0.2s | ease | 组件层 |
| 分类卡片背景变化 | 鼠标 hover | CSS transition | 0.2s | ease | 组件层 |
| TOC 折叠展开 | 点击按钮 | CSS transition（opacity） | 0.12s | ease | 组件层 |
| SVG 图标绘制 | 页面加载 | CSS animation | 1.2s | ease-out | 组件层 |
| SVG 图标浮动 | 一直播放 | CSS animation | 6s | ease-in-out infinite | 组件层 |
| 加载条流动 | 一直播放 | CSS animation | 1.4s | ease-in-out infinite | 组件层 |
| 主题切换旋转 | 点击主题按钮 | CSS animation | 0.3s | ease | 组件层 |

### 5.2 分类：按实现方式

#### A. CSS Transition（过渡动画）

用于 **鼠标交互**（hover / active），特点是自然平滑、一次性的状态变化。

**核心标准（2026-05-28 统一后）**：

```
transition-duration: 所有交互反馈统一 0.2s
transition-timing-function: ease（统一，不再混用 ease-out）
transition-property: 只过渡需要变化的属性（用逗号分隔列出来）
```

例外：
- TOC 折叠展开（无级动画）使用 0.12s，因为只是简单的 opacity 淡入淡出
- 以上是唯一允许的非 0.2s 交互过渡

#### B. CSS Animation（关键帧动画）

用于 **页面切入** 和 **持续装饰**。

| 类型 | animation-duration | animation-timing-function |
|------|-------------------|--------------------------|
| 页面进入（fade-up） | 0.35s | ease-out |
| SVG 描边绘制（draw-in） | 1.2s | ease-out |
| 持续浮动（gentle-float） | 6s | ease-in-out infinite |
| 加载条流动（stream-flow） | 1.4s | ease-in-out infinite |

### 5.3 分类：按交互方式

#### 悬浮反馈类（Hover）

所有可交互元素在 hover 时必须有视觉反馈。全站统一三种模式，**所有模式的动画时长统一为 0.2s**：

**模式一：绿线推进**（适用于列表项、导航项、TOC）

```
起始状态:  border-left: 2px solid transparent; padding-left: 0.5rem
hover/active: border-left: 2px solid var(--accent); padding-left: 1rem
              background-color: var(--bg-secondary)
              (active 额外: background-color: var(--accent-bg))
位移量: 始终 0.5rem（所有元素保持一致）
transition: background-color 0.2s, color 0.2s, border-color 0.2s, padding-left 0.2s
```

使用此模式的元素及其起始位置：

| 元素 | 起始 padding | hover padding | 位移 |
|------|-------------|---------------|------|
| `.article-card > a` | 0.5rem | 1rem | 0.5rem |
| `.docs-nav-item` | 0.5rem | 1rem | 0.5rem |
| `.toc-h2 a` | 0.5rem | 1rem | 0.5rem |
| `.toc-btn`（h2 toggle） | 0.5rem | 1rem | 0.5rem |
| `.toc-sub a`（h3 子项） | 1.5rem | 2rem | 0.5rem |

> ⚠️ 过去 `.article-card > a` 起始于 `padding-left: 0`，位移量为 1rem，与其他元素不一致。2026-05-28 统一为起始 0.5rem。

**模式二：填充推进**（适用于按钮）
```
初始状态: border: 2px solid var(--accent); 文字色 var(--accent)
          ::before scaleX(0)（绿色填充层在文字下方）
hover状态: ::before scaleX(1) 从左至右绿色填充; 文字变白色
transition: transform 0.2s ease
```

使用此模式的元素：
- `.btn-more`（"全部 N 篇" 按钮）
- `.visit-btn`（分享页"访问"按钮）

**模式三：顶部边线推进**（适用于卡片）
```
初始状态: ::before (height: 2px 绿条) scaleX(0), top: 0
hover状态: ::before scaleX(1) 从左至右展开
           background-color: var(--bg-tertiary)
transition: transform 0.2s ease
```

使用此模式的元素：
- `.docs-category-card`

> ⚠️ **统一口径规则**：如果需要添加新的可交互元素，必须从以上三种模式中选择一种，不得自创新的动画模式。所有模式的 `transition-duration` 必须是 **0.2s**。

#### 页面进入类（Page Enter）

- 所有 `<router-view>` 渲染的页面容器使用 `animate-fade-up` 类
- 效果：从 `translateY(12px)` + `opacity: 0` 过渡到正常位置
- 时长：0.35s，ease-out

#### 持续装饰类（Decoration）

- **HeroSvg**：始终浮动（上下 6px，6 秒周期）
- **LoadingDots**：光条循环流动（1.4 秒周期）
- 装饰动画必须通过 `aria-hidden="true"` 对屏幕阅读器不可见

### 5.4 防止动画不一致的规则

1. **所有交互动画使用 CSS Transition**，不要用 JavaScript 或 Web API 控制动画
2. **✅ transition-duration 全站统一为 0.2s**（2026-05-28 统一）。任何新交互必须遵循此值。唯一例外是 TOC 折叠展开（0.12s）
3. **✅ transition-timing-function 统一为 `ease`**（2026-05-28 统一）。不再混用 `ease-out`、`ease-in` 等
4. **hover 模式只有三种**（绿线推进、填充推进、顶线推进），新交互从其中选
5. **绿线推进的 padding-left 位移量统一为 0.5rem**，各元素起始位置可以不同但位移量必须一致
6. **页面进入动画统一通过 `.animate-fade-up` 类**，不各自写 keyframes
7. **选中态（active）统一加 `background-color: var(--accent-bg)`**，与 hover 态的 `var(--bg-secondary)` 形成区分

### 5.5 选中态（Active）规范

全站选中态（当前页面/当前文档/当前目录项）统一标准：

```
文字色:   var(--accent)
边框:     border-left: 2px solid var(--accent)
背景色:   var(--accent-bg)
字重:     font-weight: 500
transition: 同 hover 标准 0.2s
```

覆盖的元素：
- `.tab-btn.active` — 导航 Tab
- `.docs-nav-item.active` — 文档分类导航
- `.toc-h2.active > a` — 目录项
- `.toc-h2-toggle.active .toc-btn` — 可折叠目录项
- `.toc-sub.active > a` — 子目录项

> ⚠️ 过去 `.tab-btn.active` 没有背景色变化，导致选中态与 hover 态视觉差异大。2026-05-28 统一加上 `background-color: var(--accent-bg)`。

### 5.6 代码中的动画位置

所有动画定义集中在 `src/style.css` 的 `/* Animations */` 区域。组件内部只在 `<style scoped>` 中编写特定于该组件的动画。

```
src/style.css                      ← 全局动画（fadeUp、scrollbar）
src/components/HeroSvg.vue         ← SVG 画线 + 浮动
src/components/LoadingDots.vue     ← 加载条流动
src/pages/DocsPage.vue             ← docs-category-card 悬浮
```

## 6. 部署流程

### 6.1 部署方式

使用 GitHub Actions 自动部署到 GitHub Pages。

**触发条件**：推送到 `main` 分支

**流程**：
1. Checkout 代码
2. 安装 Node 20
3. `npm ci` 安装依赖
4. `npm run build` 构建（含 TypeScript 类型检查 + Vite 打包）
5. 把 `dist/` 目录发布到 `gh-pages` 分支（`peaceiris/actions-gh-pages` 插件）

### 6.2 构建产物

```
dist/
├── index.html
└── assets/
    ├── *.css（每个页面独立的 CSS）
    ├── *.js（路由懒加载的 JS 块）
    └── highlight*.css（highlight.js 样式）
```

Vite 的自动代码分割会将每个页面打包成独立的 JS 文件，用户只访问首页时不会加载文档页的代码。

### 6.3 base URL

项目部署在 `https://didiberber3.github.io/didiberber3-github.io/`，因此在 `vite.config.ts` 中配置：

```typescript
base: '/didiberber3-github.io/'
```

如果仓库改名，需要同步修改这个值。
